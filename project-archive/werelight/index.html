CMS를 새로 만들지 않는 선택

WordPress를 게시판과 CMS 백엔드로 사용해 운영자가 메뉴와 콘텐츠를 관리할 수 있게 했습니다. WordPress 메뉴 custom field에 category를 연결해 운영자가 메뉴를 추가하면 프론트 메뉴와 해당 게시글 목록이 함께 확장되는 구조를 만들었습니다.

Community

YouTube embed, 게시판별 추천 글, 채용 게시판, 일반 게시판에서 채용정보로 이동하는 quick menu를 구현했습니다.

Operational extension

운영자 지정 추천 글을 우선 노출하고 나머지는 최신순으로 배치하는 등 운영 요구를 CMS 설정으로 흡수했습니다.

SPA와 SEO 사이의 마찰

CRA SPA는 React bundle이 실행되기 전 실제 본문이 없어 SEO와 OG metadata 처리에 제약이 있었습니다. PHP 서버가 WordPress API에서 데이터를 조회해 URL별 title, description, Open Graph tag를 먼저 만들고 그 HTML에 React bundle을 삽입했습니다.

당시에는 React 경험을 유지하면서 본문까지 서버에서 렌더링하는 방법을 몰랐고, 이후 Next.js와 SSR을 배우면서 이 문제를 다시 이해했습니다.

이 프로젝트는 기술을 외우기보다 실제 한계에 부딪힌 뒤 새로운 추상화를 받아들이는 학습 방식의 초기 사례이기도 합니다.
