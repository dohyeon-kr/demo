아이디어를 실체로 만드는 비용 줄이기

아이디어마다 서버와 배포 환경을 새로 준비하면 프로토타입을 보여주기 전에 설정 비용이 먼저 생겼습니다. 그래서 Draft, Preview, Publish, Rollback을 한 흐름으로 묶고 프로젝트별 데이터와 파일, 함수까지 최소한의 런타임으로 제공했습니다.

설명을 오래 하는 대신 먼저 실제로 작동하는 형태를 공개하고, 실체를 기준으로 피드백하는 것이 목적입니다.

플랫폼 범위

Publishing

Draft / Preview / Publish / Rollback, 공개 디렉터리, 프로젝트 일시정지와 비밀번호 보호를 제공합니다.

Data layer

프로젝트별 SQLite DB와 Schema, Record, File, API Key, Backup 관리 기능을 제공합니다.

Functions & Relay

제한된 Server Function과 allowlist 기반 Outbound HTTP Relay, 실행·외부 요청 로그를 제공합니다.

Agent interface

OAuth MCP를 통해 Codex·Claude가 배포 API를 직접 다룰 수 있게 했습니다.

작은 플랫폼이라도 경계는 닫기

Secret은 일회성 표시 후 hash로 저장하고, path traversal과 symlink를 거부합니다. Prepared SQL과 manifest allowlist를 사용하고, 외부 HTTP는 SSRF 방어와 redirect 재검증을 거칩니다. 현재는 single-node와 신뢰 가능한 개인 사용을 전제로 하며, untrusted multi-tenant upload에는 추가 isolation이 필요하다는 경계도 명시했습니다.
