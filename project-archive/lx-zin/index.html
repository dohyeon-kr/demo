매장 키오스크

여러 매장에 배포되는 키오스크 애플리케이션의 개발 전반을 맡았습니다. PHP/jQuery 기반 UI와 매장별 데이터 가공, 배포 과정에서 생긴 반복 패치 문제를 자동화로 줄였습니다.

Period2020.04 — 08
RoleApplication Development
StackPHP · jQuery · SCSS
DataPython

매장별로 달라지는 하나의 제품

키오스크 메인 화면에서 매장정보, 카탈로그, 이벤트로 진입하고 외부 콘텐츠 중 하단 내비게이션을 유지해야 하는 화면은 iframe으로 연결했습니다. 외부에서 제공된 3D 매장 둘러보기 Viewer도 키오스크 UI 안에 통합했습니다.

Content processing

제공받은 매장 정보와 카탈로그 자료를 Python으로 전처리·정렬해 배포용 데이터로 만들었습니다.

Store configuration

매장별 PHP 설정 constant를 두고 공통 코드가 해당 설정을 기준으로 데이터와 동작을 분기하게 했습니다.

복제 구조의 운영 문제

당시에는 subdomain routing과 host 기반 분기를 잘 알지 못해 매장마다 별도 폴더를 두었습니다. 같은 코드가 복제된 상태라 한 매장의 패치가 다른 매장에 누락되는 문제가 실제로 발생했습니다.

구조를 전면 재작성하기보다 공통 파일을 각 매장 폴더에 동기화하는 script를 만들어 운영 문제를 먼저 닫았습니다.

동기화 도입 후 공통 패치 누락은 거의 사라졌고, 이미 운영 리스크가 낮아진 상황에서 폴더 구조 자체를 다시 설계하는 비용은 추가로 쓰지 않았습니다.
