제품을 끝까지 만든 첫 경험

아이디어와 브랜드 설계부터 UI, 그래픽 애셋, React 프론트엔드, WordPress 커스텀 REST API, 카카오 로그인, 데이터 로직과 클라우드 배포까지 제품 전체를 단독으로 책임졌습니다.

졸전 기간에는 SNS 전체 비전보다 “월드컵 생성 → 플레이 → 결과/통계”라는 핵심 경험의 완성을 우선했습니다.

핵심 사용자 흐름

Create

제목·설명·공개 상태와 후보 이미지를 등록하고, 다중 선택과 drag & drop으로 여러 후보를 한 번에 올릴 수 있게 했습니다.

Play

라운드를 선택하고 좌우 후보를 반복 선택해 토너먼트를 진행하며 서버에 결과를 누적했습니다.

Result

후보 순위, 매치 승률, 토너먼트 승률, 플레이 수와 좋아요·댓글을 통계 화면에 연결했습니다.

Auth & Search

카카오 로그인과 WordPress 사용자/JWT를 연결하고 서비스 내 월드컵 검색을 구현했습니다.

제품 우선순위와 회고

친구 관계, Google 이미지 검색 같은 장기 비전의 일부는 구현하지 않았습니다. 제한된 일정에서는 핵심 가치가 성립하는 흐름을 먼저 완성했고, 이후에는 임기응변식 구현의 한계를 느끼며 반복 가능한 과정과 소프트웨어 공학에 관심이 이어졌습니다.
